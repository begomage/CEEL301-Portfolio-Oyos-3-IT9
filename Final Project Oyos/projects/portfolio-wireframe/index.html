Portfolio Wireframe

A hand-drawn layout and navigation plan for a personal portfolio, mapping its key pages before visual design and development.

← Back to project albums

Project Overview

This hand-drawn wireframe plans a personal portfolio website. It sketches the home, about, portfolio/projects, skills, and contact pages and shows how visitors can move between them.

Objective

Plan the portfolio's page structure and navigation before building the digital experience.

Approach

Page layouts and navigation paths are sketched on paper, with short notes describing the intended content of each section.

Features

  • Home, about, portfolio, skills, and contact page sketches
  • Navigation flow between pages
  • Brief content notes for each page
